## 6. 不要再踩的坑

1. **抖音悬浮窗**（`com.ss.hm.ugc.aweme`）劫持 uitest 点击 —— “点了没反应”先查它。
2. **阅读页正文不在 dumpLayout 里**（ReaderKit 画在 `XComponent`）⇒ 验阅读页靠截图 + 运行时 config 日志。
3. **MCP 报某符号未使用，删的是符号不是整行**（`import { A, B }` 里 B 未用而 A 在用）。第 29 轮 A-5 就因此
   抓出 4 个变成死引用的 import（`ReaderPorts` / `ContinuePayload` / `currentPosition` / `ReaderPosition`）——
   **判据用"与 HEAD 的诊断码计数逐项比对"，不要靠肉眼**。
4. **嵌套弹窗（`openNested` / `openChildDialog`）必须自持 controller** —— 关闭要实例身份，`DialogHost.open()` 会关掉父窗。
5. **往方法之间插代码，锚点要取“上一个方法结束”**，取“下一个方法签名”会插进函数体（第 26 轮实际把 `isExistBooks` 劈开）。
6. `Measure-Object -Line` 与真实行数不符（跳过空行），核行数用 `(Get-Content x).Count`；
   与 `git diff --stat` 的数字也可能差几行（行末换行计法不同），别当 bug 查。
7. `docs/` 被 `.gitignore` 忽略 ⇒ 提交文档必须 `git add -f`。
8. **注释里的行号引用会腐烂**（§75.6-1 实证：`BookMark.ets` 声明"`IndexShelf.ets:188` 有调用"，
   实际早已没有）⇒ 写证据优先写语义 + 可复现的搜索口径，行号只作辅助。
