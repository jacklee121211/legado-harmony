## 5. 关键"不要再踩"的坑

1. **抖音悬浮窗**（`com.ss.hm.ugc.aweme`）会劫持 `uitest` 点击 —— 所有"点了没反应"先查它。
2. **阅读页正文不在 dumpLayout 里**（ReaderKit 画在 `XComponent`）⇒ 验阅读页只能靠截图像素扫描 + 运行时 config 日志。
3. **MCP 报某符号未使用时，删的是符号不是整行**（`import { A, B }` 里 B 未使用而 A 在用）。
4. **嵌套弹窗（`openNested`/`openChildDialog`）必须自持 controller** —— 关闭需要实例身份，`DialogHost.open()` 会关掉父窗。
5. `Measure-Object -Line` 与真实行数不一致（会跳过空行），核行数用 `(Get-Content x).Count`。
6. `docs/` 整个目录被 `.gitignore` 忽略 ⇒ 提交文档必须 `git add -f`。
