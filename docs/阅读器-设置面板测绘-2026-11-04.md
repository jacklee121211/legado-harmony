## 2. 数据流：它依赖页面多少东西（这就是抽取成本）

脚本对 9032–9795 去注释后统计：

**读取页面字段 51 个**，其中真正是页面状态的 **12 个**：

| 字段 | 装饰器 | 面板里的用途 |
|---|---|---|
| `colorMode` | (页面普通字段，`@8883`) | **32 处**三元着色（面板跟阅读器日/夜，不跟整机） |
| `isLuminanceFollowSystem` | `@State:734` | 随系统开关 |
| `isScreenState` | `@State:735` | 常亮开关 |
| `devMode` | `@State:912` | 标定区门禁 |
| `calibTopPx` / `calibWidthRatio` / `calibLineMul` | `@State:1372/1373/1374` | 标定显示与微调 |
| `calibLabel` / `calibCounts` | `@State:890/897` | 标定读数 |

| `bgFocus` / `themeMode` / `bgTexId` / `bgCustomId` / `customTexSeq` / `bgTipCh` / `fontTarget` | `@State` | 背景家族焦点/材质/自定义色/草稿分流 |
| `lumRollbackTo` / `screenRollbackTo` / `bgSliderW` | (普通成员) | 回退哨兵、滑条宽度测量 |

**写入页面状态的只有 6 个**：`isLuminanceFollowSystem`、`isScreenState`、`bgBlurOn`、`bgBlurRadius`、`fontTarget`、`bgSliderW`（+ 两个回退哨兵）。**其余全是"读 + 调方法"** —— 面板本质是"薄壳"，能力都在页面的 handler 里。

**调用页面方法 15 个（能力面）**：`setDraft`、`nudge`(6×)、`resetCalib`、`sliderSelectedColor`(4×)、`customEditVisible`(4×)、`isCustomBgFocused`/`isTexOverflowFocused`、`onCustomBgSliderChange`(3×)、`commitCustomColor`、`toggleCustomBg`、`syncCustomBgGlobal`、`saveCustomBg`(2×)、`applyTextureBg`(2×)、`openFontDialog`、`openTexDialog`、`openSchemeDialog`、`openSaveSchemeDialog`、`openVipDialog`(3×)、`bgTipX`、`customBgHex`/`customFontHex`(各 2×)、`bgBlurTierIndex`。

**依赖页面里另外 3 个 `@Builder`**：`ReadModeRow()`、`FontRow()`（色卡行）、`swatchRows()`/`SwatchCore()`（背景格）。

> 结论（抽取成本）：**整块变成 `@Component` 需要 12 个状态 + 15 个回调 + 3 个 `@BuilderParam`**。这不是"搬文件"，是"重定义接口"。

## 3. 四条关键机制（拆之前必须记住）

1. **`@Builder` 与页面共用一个状态作用域**：面板现在挂在**页面**的 `@Builder` 上，`this.xxx` 直接是页面状态 ⇒ 任何字段变化都会让面板按页面渲染范围刷新。**换成 `@Component` 就有了自己的状态作用域与更新边界**，刷新粒度会变 —— 这是本批唯一真正难的地方（不是语法，是渲染语义）。
2. **SDK 硬约束（原文）**：`…/ets/component/custom_dialog_controller.d.ts:55-69`
   ```
   * To listen for data changes in the builder, use the @Link or @Consume decorator; other decorators, such as @Prop and
   * @ObjectLink, do not apply.
   ```
   ⇒ 若把内容直接塞进 `settingDialog` 的 `builder`，只能 `@Link`/`@Consume`（这也是听书面板用 `@Link` 的原因）。
   **当前面板绕开了它**：内容走 `@BuilderParam`（`ReaderSettingDialog.ets:50`），仍是页面 `@Builder`。
   ⇒ 抽取时必须选：**(D1) 只把面板内部的子区块做成 `@Component`**（它们不是 dialog builder 的参数字段，不受上述限制），或 **(D2) 整块组件化 + 全 `@Link`**。
3. **草稿态 + 分流**：自定义颜色是 `draft*` 草稿 → `保存` 才提交；`fontTarget` 决定这批草稿作用于"背景"还是"文字"。**不能把草稿和在用值合成一个字段**（用户在 `保存` 之前不该影响正文）。
4. **回退哨兵是行为的一部分**：`$$` 双向绑定 + 程序化回退会二次触发 `onChange`，两个 `*RollbackTo` 是**按值匹配**的补丁，抽组件时必须原样保留（换组件后 `$$` 的绑定对象也变，这里最易回归）。
