## 0. 设计哲学（用户原话蒸馏，不得偏离）

1. **父子天然传承**：分组是多级目录，父隐藏则子不可见；父删除/解散，子按规则**自然提级**。
2. **两种架构**：**祖架构**（根目录 → 未分组 + 一级目录）与**父子架构**（任意层级内部）。
   显示与操作**共用同一套 UI 与逻辑**，靠"模式"区分，不靠"页面副本"。
3. **未分组是天然接纳者**：不属于任何自定义分组的书自然落在未分组；它**不参与"移动至"的树**，
   也不能被当作父容器使用。
4. **选中不可穿透**：批量里"本分组"选中 = 直属书 + 全部子分组；不存在"选 A 又选 A 里的书"。
5. **操作即真相**：任何写操作成功后，全链路**立刻**以新数据为准（数据总线单一事件）。
6. **外观零改动**：重构只换"数据通路与容器骨架"，卡片/宫格/封面/圆角/颜色一行不改。

## 1. 冻结语义（用户 2026-11-02 拍板，实现禁令）

| # | 语义 | 实现禁令 |
|---|---|---|
| S1 | 未分组只作"书的天然归属" | 「移动至」的树**任何架构下都不显示**未分组 |
| S2 | 隐藏分组在两种批量管理里都不显示 | 只在"分组管理"树里可见，且点它出**四按钮**（取消隐藏/解散/删除/取消） |
| S3 | 选中不可穿透 | 选本分组 ⇒ 直属书 + 子树全选；反之子集全选 ⇒ 本分组选中（闭环） |
| S4 | 根层目录的 `parentId = 0` | **禁止**把根层目录的 parentId 写成未分组的 id |
| S5 | 书回落未分组 | 解散/删除时书落到**父级**；父级是根 ⇒ `bookGroup = 未分组(3)`，`parentId` 不变 |
| S6 | 结构变更 ⇒ 选中集失效 | 任何解散/删除/移动导致 id 变化后，**选中集立即清空**，禁止沿用旧 id |
| S7 | 弹窗：子进父出、子退父进 | 父**真关**（不保留实例）；子关闭后**重新 new 父并重新取数** |
| S8 | 数据总线 | 一次操作 **只发一次** `GroupChanged{version, changedGroupIds, changedBookIds}` |

### P4 根因取证（2026-11-02 第 17 轮，U1「分组与书籍滑动割裂」）

| 证据 | 位置 | 说明 |
|---|---|---|
| 外层是 `Column`，**分组网格在上、书籍列表在下** | `components/BookContentRefresh.ets:598 Column()`，其内先 `BookFolder`（R8 import）再 `BookContent`（R613/R625） | 两个兄弟节点，各自独立 |
| 分组网格**本身不是滚动容器** | `BookFolder.ets:507 GridRow(...)` | 只排版不滚动 ⇒ 位置被固定 |
| 书籍列表自带滚动 | `BookContent` 内 `List` + `lanes()` | 只有它滚动，所以"分组死死钉住、书籍单独滑" |

**结论**：U1 不是"样式问题"，是**容器结构问题**——分组与书籍分属两个兄弟节点，其中一个不自带滚动。
**目标形态**（对齐子分组批量管理页）：**单一 `List`**：
1. 第一个 `ListItem`（或 `ListItemGroup` 的 header）放分组卡片网格；
2. 后续 `ListItem` 放书籍（用 `lanes` 保持宫格列数，与 `ShelfPrefs.effectiveColumns` 同源）；
3. 两者共享同一个滚动偏移 ⇒ 分组随内容一起滚，且"分组优先"靠**顺序**保证（不再靠固定）。

**改造顺序（下一轮执行）**：
1. 先给 `BookContent` 增加 `header?: CustomBuilder` 能力（不动现有列表逻辑）；
2. `BookContentRefresh` 在开关 `USE_UNIFIED_SCROLL` 下把 `BookFolder` 作为列表头；
3. 真机对照：进 1 → 分组+书籍一起滚；返回根 → 无闪烁；底部 dock 不被遮挡；
4. 通过后切默认，删旧分支。

它与订阅端 `BookManagePage` 打的 `[GRP-EVENT] 结构变更 → 已清空选中集 (v=<同一个 n>)` **成对**。三态判定表（以后照这个查，别再瞎猜）：

| 现象 | 含义 |
|---|---|
| **连 `[GRP-EMIT]` 都没有** | 根本**没发事件**（那条写库路径没走到 emit） |
| `[GRP-EMIT] … listeners=0` | 发了，但**当时没有任何订阅者**（批量页没挂载 —— 设计如此，不是 bug） |
| `[GRP-EMIT] … listeners>0` 但没有 `[GRP-EVENT]` | 订阅者在，但**判定条件没命中**（如 `changedGroupIds` 非空 ⇒ 不算结构变更） |
| 两条都有、v 同号 | 整链路通，且**恰好一次**（S8 成立） |
