# 多级文件夹（分组）—— 方案、决策、实现计划（2026-11-01）

> 本文是**跨会话记忆**。任何 agent 接手前先读它，再动手。
> 配套：`docs/交接-2026-11-01-阅读器亮暗与多设备.md`（阅读器侧，本轮不碰）。
> 本轮范围：**只做多级文件夹**；压缩包导入**不实现**，只预留接口（见 §4.8）。

---

## 0. 一句话

`book_groups` 加一个 `parentId`（0=根级），把「分组=标签」升级成「分组=标签+文件夹树」：
分组卡片改成 2×2 内容预览、进入父组用横向滚动路径条、移动至用树形选择器、
删除=真删书 / 解散=不删书、分组长按可碰一碰整组分享（>500 本游标接续）。

## 1. 用户拍板（2026-11-01，逐条）

| # | 问题 | 结论 |
|---|---|---|
| 1 | 冲突判定口径 | **任一命中**：书名+作者 相同 **或** 文件大小+修改时间 相同 |
| 2 | 覆盖时旧书文件 | **物理删除**（旧书记录/书签/进度一并清） |

| 4 | 删除 vs 解散 | **删除=删书（含文件/书签/进度）；解散=不删书**（当前代码两处实现不一致，见 §5.3） |
| 5 | 分组移动遇到同名子组 | 弹提示：**合并 / 重命名**；合并则直接进冲突流程（闭环） |
| 6 | 分组卡片 | **2×2 内容预览**：子文件夹优先、书在后；>4 个不处理；卡片可放大；外框用**线条**（不用模糊）；单层/多层统一 |
| 7 | 层级上限 | **10 层**（硬限） |

| 12 | 系统单元 | 不动（注意：UI 里已屏蔽「本地」「未分组」「书单」chip，见 §5.5） |

## 4. 设计

### 4.1 数据模型

```
book_groups:
  + parentId INTEGER NOT NULL DEFAULT 0   -- 0 = 根级
books.bookGroup 仍存「叶子分组」id；父组也可直接放书（用户拍板 2）
```

- 迁移：旧库由 `existsTable()` 自动 `ALTER TABLE ... ADD COLUMN parentId INTEGER DEFAULT '0'`；
  旧数据全部 `parentId=0` ⇒ 行为与现在完全一致（零回归）。
- 加字段要同步 **4 处**：建表 SQL、fields、实体+两映射、`getPartialColumn()` —— 本轮已全部改完。
- 深度：根级 = 1；`MAX_GROUP_DEPTH = 10`。

### 4.2 树工具 `common/group/GroupTree.ets`（已实现）

纯函数：`build(list)` / `childrenOf` / `roots` / `depthOf` / `pathOf` / `pathNames` / `isDescendantOf` /
`descendantIds` / `subtreeIds` / `subtreeHeight` / `canMoveTo` / `canCreateChild` / `hasSiblingNamed`。
脏数据（父不存在、自环）按根级处理，不让整棵树消失。

### 4.3 分组卡片 = 2×2 内容预览

- 外框：`Stack` + `.border({width:1, color})` + 半透明底（**不用模糊**，用户拍板）；
- 内部 2×2：子文件夹在前、书在后，最多 4 格；`>4` 不提示（用户拍板）；
- 子文件夹格 = 现有文件夹卡片缩小版（封面 + 叠层装饰）；书格 = 书籍封面；
- 层级标记：`depth ≥ 2` 时显示「N 级」小角标；
- 统计：**直属**（子文件夹数 + 直属书数），不递归；
- 空组：显示默认封面；
- ForEach 键必须并入"子组数/直属书数/封面"等影响显示的字段（沿用 `BookFolder.ets:268-289` 的教训）；
- 列数：沿用 `ShelfPrefs.effectiveColumns()`，2×2 随卡片宽度自适应。

### 4.4 进入父组 + 路径条

- 进入父组后显示：子文件夹卡片行 + 该组直属书（两者都在同一页，子文件夹在上）；
- 底部路径条：`Scroll(横向)` + 每级一个 chip，**点第 N 级直接跳到第 N 级**；过长可横滑；
- 左侧常驻「新建」按钮：symbol `plus_circle`（`sysResource.js:3636` 实测存在），
  图标/动效/手感复用 `addBookTypeDialog` + `Haptics.tap()` + `runJellyClick`；
- 路径栈放 AppStorage（如 `SHELF_GROUP_PATH_IDS`），不再依赖单一 `SHELF_CURRENT_GROUP_NAME`；
- ⚠️ 进入分组时仍必须 **先写 `GROUP`、后写 `bookTypeNumber`**（`IndexShelf` 的 `@Watch('changeGroup')` 会兜底）。

### 4.5 移动至（树形选择器）

- 新组件 `GroupTreePicker`（`List` + 展开/折叠，官方 FAQ 方案二）：
  顶部固定「未分组」；每个节点可展开；当前所在组置灰；**禁止选自身/子孙**（`canMoveTo`）；
- 同时服务「书籍移动」与「分组移动」；分组移动遇到同名子组 → 弹「合并 / 重命名」（合并进冲突流程）；
- 底部提供「新建子组」（≤10 层时可用）。

### 4.6 删除 / 解散 / 冲突

**删除（真删）**
1. `GroupTree` 收集子树；
2. 每个组 `BooksDao.queryBooksByGroupId` → `booksUtils.delBooksById`（清书签/进度/封面）；
3. `bookGroupUtils.delGroupById`；
4. 二次确认弹窗显示「将删除 X 个子文件夹、Y 本书（不可恢复）」。

**解散（不删书）**
- 书 → 父组；根级 → 未分组；
- 含子组时弹「一起解散 / 子组保留（上提一级）」；
- 关闭"空组自动解散"：`BookSelectGroupDialog.cleanupOldGroup()` 不再调 `dissolveIfEmpty`。

**冲突（覆盖/重命名/跳过）**
- 触发：合并（分组移动同名合并、解散并入父组）；
- 判定：书名+作者 或 大小+时间 任一命中；
- UI：列表显示 书名/大小/时间/所在目录，单条选择 + 「全部覆盖 / 全部重命名 / 全部跳过」；
- 覆盖 = 删旧（记录+文件+书签+进度）；重命名 = `书名 (2)` 进目标；跳过 = 不并入，落未分组。

### 4.7 分组长按 → 碰一碰 / 隔空传送

- `FolderInfoDialog` 顶部加两个标志（沿用 `ShareGuideTip` 视觉）；
- 打开时 `BookShareBridge.acquire` + `setSelection(buildSelection(该组全部书))`；关闭 `release`；
- 组内书 > 500：先切片前 500 + 本地存游标（Preferences `GroupShareCursor_<groupId>`），
  提示「再碰一次发送剩余 X 本」，用户手动再触发时从游标继续；
- 官方硬限：500 项 / IPC 200KB / 批量仅 `UDMF.File`。

### 4.8 压缩包预留（本轮不实现）

- `addGroup(parentId)` 已天然可用；将来导入器只需传 `mode: 'mirror' | 'flat'`：
  `mirror` = 按 zip 内目录建多级分组（≤10 层），`flat` = 全平铺进当前分组；
- 本轮**不写**任何解压代码。

## 5. 与现有代码的关系 / 风险（必须处理）

1. **删除/解散实现不一致**：`FolderInfoDialog.deleteGroup` 与 `disbandGroup` 都调 `delGroupById`（只删组）⇒ 按新语义修正「删除」为真删；管理弹窗已有正确实现可参照。
2. **写库未 await**：`booksUtils.updateBooks` 的 `forEach`、`BooksDao.updateBookGroup` 的 `forEach(async)` ⇒ 移动/解散后卡片"共 0 本"、点进去空白（用户报告的 bug 可疑点之一）；本轮统一改 `for` + `await`。
3. **`addGroup` 未 await**：新建分组后立即刷新可能读不到；本轮补 `await`。
4. **`@Watch` 顺序陷阱**：`openGroup` 必须 `GROUP` 先、`bookTypeNumber` 后（`BookFolder.ets:196-213` 注释已写明）；多级进入父组沿用。
5. **返回按钮依赖单一分组名**：`GroupType` 每次刷新用 `chipHighlightId` 反写 `SHELF_CURRENT_GROUP_NAME` ⇒ 按钮会消失；改路径栈后由路径驱动。
6. **`book_groups.bookIds` 是陈旧冗余列**（只在移动时追加，导入/删除不同步）⇒ 一律不读它做渲染/统计。
7. **书与分组的特殊值**：`bookGroup=3` 未分组、`4` 本地兼容、`2` 全部；分组系统单元 id 1/2/3/4 与它们同名不同表，别混。
8. **ForEach 键**：2×2 预览要多加"子组数/直属书数"等字段，否则广播了不刷新。
9. **分享上限**：>500 本必须切片，否则 bridge 直接拒绝（`BookShareBridge.ets:589-593`）。
10. **深度与防环**：UI 与 `GroupTree` 双端校验；移动/新建都要过。
11. **迁移方向**：只加列、不改旧数据；回退只需把 `parentId` 全部置 0（或忽略该列）。
12. **性能**（本轮不优化，但记录）：2×2 预览 × 列数（手机 3 列 = 12 张封面）需要缩略图/缓存，否则滚动卡顿。
