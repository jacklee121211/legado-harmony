# 阅读器跨设备参数实测记录（2026-11-01）

> 目的：把"留白/字重按设备怎么变"从猜测变成实测数据。本文所有数字均来自真机/云真机日志与截图，可复查。

## 1. 结论速览

| 结论 | 依据 |
|---|---|
| 引擎上下留白是**内建页眉页脚**，无 API 可调 | 官方 FAQ `faqs-reader-3` 原文；`ReaderSetting` 13 字段无 margin |
| 缩放 1.05 会破坏几何（正文越过底部信息条） | 手机 844vp：776×1.05=815 > 信息条 808 ⇒ 必须位移 ⇒ 换机露底 |
| 引擎页眉在**屏幕 px** 口径下恒定 ≈160px | XT2 四次运行：158/159/158/165px，宽度 447→1249vp、密度 2.55/3.0 都不变 |
| 探针改 `fontSize` 对引擎**不生效** | 14/16/20/24/28 五档 MEASURE 完全相同 |
| 自绘字重需按密度补偿 | m80(3.375) 需 0；PuraX(2.55) 需 +100；同值无法兼顾 |

## 5. 当前实现（代码位置）

- `ReaderPage3.ets`
  - `ENGINE_TOP_MARGIN_VP = 88` / `ENGINE_BOTTOM_MARGIN_VP = 62`（默认）。
  - `ENGINE_MARGIN_BY_DENSITY = false`：置 true 时用 `160/density + 40.6`（m80 仍 88）。
  - `selfDrawnFontWeight()`：`boost = clamp(round(120 × (3.375 − density)), 0, 200)` ⇒ m80 0 / PuraX 99 / 平板 135。
  - 信息条**不再驱动正文位移**；`readerKitInfoWinShiftY()` 只返回 δ。
  - 上下档保焦点：`ReaderScrollView` 的 inset 变化 → `scrollToIndex`。
  - 避让区监听 `avoidAreaChange` + `viewportSelfCheck()`。
- 底部 dock：`HdsTabs`（API≥23），关闭 `systemMaterialEffect`（四档统一普通条）；低版本退回原生 `Tabs`。

## 7. 未解决 / 待验证

1. 三屏 `pitch` 异常（81/95 vs 45）——疑似测量算法，需要换算法重测；
2. 云机会话间 density 会变（2.55 ↔ 3.0），跨会话只能比 px；
3. 引擎页眉 160px 与 App 实际 88vp（m80）/100vp（PuraX）之间的换算关系尚未闭环——需要一次"同字号下 App 与探针"的对照；
4. 仿真/横滑档 dock 无玻璃（XComponent surface 无法被材质采样），已放弃玻璃、四档统一普通条。
