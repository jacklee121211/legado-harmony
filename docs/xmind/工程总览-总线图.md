# 阅读器工程总览 · 总线图

> 读法：主干是"事实怎么流"（数据总线），分支是挂在这条线上的功能与 UI，每个节点标题就是它的一句话逻辑。
> 这不是代码索引：不列文件树，只在需要时给出最窄的定位。
> 规模实测（2026-11-03）：283 个 .ets / 112,497 行；pages 67（44.8k）、common 103（36.2k）、tts 29（12k）、componets 52（8.2k）、database 18（5.8k）。
> 证据等级：真机实测 > 官方 SDK 声明 > 官方文档 > 静态检查（MCP/lint）> 直觉；文档与代码冲突时以代码与真机为准。

## 数据总线：只有事实在总线上

### 持久层是唯一可信来源

#### 六张业务表
> books、book_groups、readRecord、book_history、bookmarks、readDaily（表名来自各 DAO 的 TABLE_NAME 常量）。

#### 表结构由 AppDatabase 生成
> database/AppDatabase/index.ets（2518 行）是离线快照；建表是懒建表：database/index.ets 的 initAllTable() 逐表调 XxxDao.initXxxTable()。

#### DAO 是唯一 SQL 入口
> 谓词式 DbUtil.update/delete；SQL 字符串只允许出现在 database/ 内（闸门硬约束：UI 层 DbUtil.executeSql = 0）。

#### 改名是一条级联事务
> books 主表改名 + readRecord / book_history / bookmarks 的旧名同步，同一个事务提交；bookmarks 目前是历史空表（0 行属设计如此）。

#### 删除是"数据 + 派生"一起清
> 走 booksUtil.delBooksById：行、阅读记录、历史、封面文件一并处理，避免留下指向不存在书的记录。

### 内存里也只放一份事实

#### GroupStore 是分组树唯一真源
> 页面不再各自建树：全仓 GroupTree.build 从 12 处收敛到 9 处（真源 2 + 工具 2 + 弹窗 2 + 页面 3），且预算只许降。

#### fillRealBookIds 是书数唯一算法
> 只重写内存对象的 bookIds（不落库），三个调用点覆盖书架 / 批量 / 分组管理；任何"共N本"都必须来自它。

#### ShelfRefresh 是刷新唯一写点
> 原来 56 处散落自增，收敛为 4 个入口（groups / books / structure / sort），仍然 bump 同一批键，行为等价。

### 事件把"变化"传给视图

#### 一次操作只发一条事件
> 结构变更发 groups=[]，非结构变更发 groups=[id]；批量删两个分组也只有一条。

#### 结构变更必须清选中集
> 增删、移动、可见性变化一律清空批量选中，避免"选中了已经不存在的东西"。

#### 订阅方只读真源
> 页面收到事件后重算投影，不缓存第二份事实；页面可以有自己的视角，但结论每次现算。

## 分组域：祖架构 + 父子架构

### 两种架构是一套逻辑

#### 祖架构＝根目录
> 未分组 + 一级自定义分组。未分组是系统固定元素：不可长按、不可删除改名，只提供未分组书籍的展示与操作。

#### 父子架构＝天然继承
> 每一级是父的唯一子、子的唯一父；显示层与操作层共用同一套 UI 与逻辑，任意层级唤起功能完全一致。

#### 层级不是限制，是结构
> 移动、隐藏、删除、解散都沿父子关系传递；父子链不断即结构不破。

### 计数口径（2026-11-03 定稿）

#### 浏览态：只说这一层
> 卡片显示直属书 + 直属子文件夹数（1 = 共2本 · 2个文件夹；进入 1 后 11 = 共1本 · 1个文件夹）。

#### 批量态：选中它会带走多少
> 根级批量 = 子树累计（1 = 共5本）；进入分组批量 = 全选行子树累计 + 子级各自子树累计（11 = 共2本）。

#### 父层批量不穿透
> 只显示 本分组（全选行）+ 直属子级 + 本级直属书；不显示孙级（111 不出现），因为孙级属于"子级的内部"。

#### 勾选闭环
> 点全选行 → 子级与书全选；手动勾满子级与书 → 全选行自动选中；再点一次全部取消。

### 唯一写入口 GroupMutation

#### 删除（可保留子文件夹）
> 父删、本组直属书删，子文件夹完整上提一级；子级的父改为原父，数据实时更新。

#### 解散（可保留子文件夹）
> 本组直属书与子文件夹都上提到父级，然后删本组；书与文件夹都回到父级之内。

#### 隐藏（天然继承）
> 隐藏父则其书与子一并隐藏；父处于隐藏时，子不可被单独显示。

#### 移动至
> 文件夹树以"当前根"为根并在当前节点标"当前"；不能移入自己与后代（子不能食父）；书籍可移到任意目录。

#### 合并 / 改名 / 封面 / 新建
> 全部走同一入口：写库 → 刷真源 → 发一次事件；UI 不再各写一套。

### 长按分组弹窗

#### 顶部说清"这是什么"
> 名称 + 共X本/文件夹数（单层不显示文件夹数）+ 碰一碰/隔空传送 + 七项功能。

#### 七项功能
> 重命名 / 置顶 / 移动至 / 封面样式 / 隐藏分组 / 解散分组 / 删除。

### 批量管理两种入口

#### 组架构根级
> 只列自定义分组（不显示未分组），卡片数字为子树累计，提供移动/隐藏/解散/删除/分享。

#### 父子架构任意层级
> 全选行 + 直属子级 + 直属书；选中子级等于选中其内部全部；功能与逻辑逐层一致。

## 书架域

### 四个入口各有语义

> 分组（祖/父子浏览）、全部（跨分组平铺）、最近（按阅读时间）、未分组（系统书集合，无分组卡）。

### 卡片与列表

> 列表/宫格两模式；宫格列数走 ShelfPrefs.effectiveColumns（sm3/md4/lg5/xl6），手机恒 3 列不回归。

### 刷新只有一条路

> 结构变更刷分组+书籍；书籍变更只刷书籍；排序切换刷排序键；页面不再自己加计数器。

### 选中集只有一种语义

> 选中即 id 集合（SelectionKeys）；不穿透；结构变更后清空；批量操作以选中集为唯一输入。

### 搜索与书架同谓词

> 搜索、全部、分组都必须能对同一本书给出相同结论，避免"书架有、搜索没有"。

## 阅读器域

### 三套引擎按需路由

#### ReaderKit（仿真 / 横滑）
> 官方组件 ReadPageComponent，CSS 排版引擎；分页按引擎每页行数。

#### 自研（上下滚动 / 无动画）
> ReaderPageNoAnim + ReaderScrollView + EngineLines（ArkGraphics 2D）；与 ReaderKit 逐像素对齐，断行差 ±1 字是物理极限。

#### PDF
> PdfViewerPage（官方 PdfView 组件版，主路径）与 PdfReaderPage 两条，按入口择一。

### 核心页是最大技术债

> ReaderPage3.ets 13,016 行、137 个 @State、23 个 @Builder：能跑，但重构必须先做设计，不能顺手拆。

### 版式与视口

#### 视口不会自己跟着窗口
> 进书前必须用 AppStorage 的窗口像素主动校准 viewPort，否则第二次进书会用上一次的旧视口排版。

#### 可用页高 ≠ 窗口高
> 沉浸层预算一律按整屏算，页边界与普通模式同源（都按引擎每页行数）。

### 阅读侧能力

> 目录 / 书签 / 进度 / 字体（自定义字体必须注册 resourceRequest 才生效）/ 背景 / 纹理 / 翻页方案 / 睡眠定时。

### 沉浸与动效

> 一镜到底仅手机启用（非手机禁用，避免毒化渲染：固定尺寸裁切盒 + 不重算）；转场统一走 UiMotion。

## 听书域（Edge TTS）

### 一条流水线

> 章节 → 分句（SentenceSplitter）→ 合成（EdgeTtsClient / LocalTtsClient）→ 解码（NativeDecoder）→ PCM 播放（PcmPlayer）→ 逐字高亮。

### 引擎与声库

> Edge 在线声库 + 本地声库，按设置与网络择一；声库列表来自 EdgeVoices / LocalVoices。

### 连续性

> 暂停拼接（PauseSplicer）、章节衔接、后台与锁屏控制、会话封面（SessionCover）。

### 朗读内容过滤

> SpeakFilter 处理"哪些内容该念"（标注、重复行、特殊符号），避免念出不该念的东西。

## 导入与分发

### 本地导入

> 格式白名单 + 归一化（BookNormalizer）；DOC/DOCX 已不支持，老书给"导出原文件 / 从书架删除"两个明确出口。

### 网页传书

> WifiBookServer（2997 行）+ 分块上传（断点续传只补缺块、100MB 上限、扩展名白名单）；web 产物有新鲜度闸门。

### 碰一碰 / 隔空传送 / 分享

> BookShareBridge 统一收口：进页 acquire、离页 release，避免"在别的页面却发出本页选中"。

### 外部分享接收

> ShareReceivePage 承接系统分享入口，落到导入同一条路径。

## 交互与弹窗体系

### 弹窗只有一个出口

> 所有弹窗经 DialogHost 打开；scripts/check-dialog-usage.mjs 守着，CTRL_BUDGET 只许降。

### 按钮数由结构决定

> 单层/书籍 = 2 按钮；多层含子文件夹 = 3 按钮（保留子文件夹 / 全部删除 / 取消）；隐藏分组在树中被点到 = 4 按钮（最左多一个"取消隐藏"）。

### 菜单与手势

> 分组、书籍两套菜单；右滑返回由一镜到底 delegate 的 PanGesture 提供（fingers=9 才关得掉），与阅读页自绘手势不抢。

## 多端与形态

### 断点必须是活的

> currentBreakpoint 由 EntryAbility 首帧 + windowSizeChange 维护（曾长期是死代码，任何 @StorageProp 都恒为默认值）。

### 2in1 / 平板

> module.json5 的 deviceTypes 必须含 2in1，否则根本装不上；列数与限宽按断点变化。

### 避让与手势区

> 悬浮页签的蒙层必须显式关（gradientMask 透明）；内容避让走 contentEndOffset，不要给滚动容器留底部外边距。

## 工程纪律（可执行）

### 三道闸门

> check-dialog-usage（弹窗出口）、check-single-path（旧名 0 / UI SQL 0 / GroupTree≤9 / 写直连 0 / 刷新写点 0）、check-web-artifacts（产物新鲜度）。

### 提交与版本

> 提交首行带版本号；版本号沿用当前值、不自行加一；post-commit 钩子同步 app.json5 与 VersionLogData。

### 改动纪律

> 先讲机制再动手（为什么存在 / 谁调用 / 改错代价）；单一通路；发现问题先报不改；探针用完即删。

### 验收方式

> 无真机时：build + MCP check + 三道闸门；有真机时按《一次性真机验收清单》逐条走，出问题立即停手留证据。

## 已知边界与待决

### 最大技术债

> ReaderPage3 13k 行（三引擎共用入口）；InviteCodeManager 10k 行（硬编码邀请码白名单，需确认是否应外置到服务端）。

### 已定稿、别再讨论的口径

> 计数（浏览=直属 / 批量=子树）、父层批量不穿透、一操作一事件、弹窗单出口。

### 【待验证】

> 2026-11-03 的 A/B 两线改动全部未经真机：构建通过、闸门绿，只证明没有明显断裂，不等于真机上正确。

### 小项技术债

> 目录拼写 componets/ 与 components/ 并存；console.log 85 处；TODO/FIXME 11 处；InviteCodeManager 与 WifiBookServer 是"大文件孤岛"。
