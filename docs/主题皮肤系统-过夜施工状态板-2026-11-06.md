  是原子操作：**谁建成功谁干活，建失败 = 已有轮持锁**——不存在"两个都以为没人"的竞态窗口。
- 锁内 `stamp` 文件 = 最近存活时间戳（秒）。持有轮**每完成一项刷新一次**；
  非持有轮读到 stamp 距今 <12 分钟 → 空转让路；≥12 分钟 → 判上轮异常死亡，
  报告区记一笔后删旧锁重新竞争接管。
- 收工：删锁目录 + 心跳改回「空闲」。崩溃持锁 → 由 12 分钟判死机制兜底。
- 即便理论重叠，损害有界：文件工具护栏（Write 需先读 / Edit 需匹配原文 / git index.lock
  串行化）让后到者失败而非破坏；每项独立提交，最坏是重复劳动，不是数据损坏。
