# 阅读器三概念归属（2026-11-03，P2/R4 定稿）

> 背景：本项目阅读器里 **txt / 非 txt / pdf 是三套概念**（用户口径）。
> P1 之前"进哪个页"的判断散在 2 处、且另外 6 个入口完全没判断 ⇒ 同一本 PDF 因入口不同进不同页。
> 本文是**唯一归属表**，代码侧的对应实现是 `common/reader/ReaderEntry.ets`。

## 一、入口决策（唯一实现：`ReaderEntry`）

```
book.bookUrl
   │
   ├─ .doc / .docx（UnsupportedDoc.isUnsupported）──→ 调用方弹出「暂不支持」卡（带导出/删除）
   │
   ├─ .pdf + FMT_PDF_USE_PDFVIEW ──────────────→ PdfViewerPage（RouteName.PDF_VIEWER）
   │
   └─ 其它（txt / epub / mobi / azw3 …）───────→ ReaderPage3（RouteName.READER）
                                                  └─ 按翻页模式可能转 ReaderPageNoAnim
```

- **唯一出口**：`ReaderEntry.open(uiCtx, book, opts)` / `prepare()+launch()`；
  全仓 `push(RouteName.READER|PDF_VIEWER)` 只允许出现在 `ReaderEntry` 内（已实测：仅 2 处，都在该类）。
- **一镜到底**：`prepare()` 必须在**点击瞬间**同步调用（要靠封面组件 id 拍几何）；
  列表封面 `coverWidth=60 / longtakeCorner=4`、宫格 `100 / 10`。
- **"转场进行中"闸**：`BookInfos` / `BookInfoGrids` 各自保留 `openReaderWhenIdle(launch, tries)`
  （防"纯黑阅读器"），但闸内只做 `ReaderEntry.launch(launch)`，不再关心进哪个页。

## 二、三个页面各自的职责

| 页面 | 职责 | 谁在用 |
|---|---|---|
| `PdfViewerPage`（`RouteName.PDF_VIEWER`） | **PDF 唯一阅读页**（官方 PdfView 组件；翻页/缩放/大纲都在它内部） | 所有 pdf 入口（书架、继续阅读、详情、我的中心、阅读统计） |
| `ReaderPage3`（`RouteName.READER`） | **txt / epub / mobi / azw3** 的阅读页（ReaderKit 排版；仿真/横滑） | 所有非 pdf 入口 |
| `ReaderPageNoAnim` | 上下 / 无动画翻页档（由 `ReaderPage3` 按 `READ_MODE` 转入，不是路由入口） | `ReaderPage3` 内部分流 |
| ~~`PdfReaderPage`~~ | **已删除**（P1/R2）：自研图片阅读页，开关恒 false，且 `BooksDao.partialUpdate` 直写事实 | — |

## 三、`ReaderPage3` 里的 PDF 残留（已 @deprecated）

`ReaderPage3` 仍保留 `isPdfBook` 与围绕它的缩放态（`pdfZoomPct` / `PDF_ZOOM_ACTIVE` / 双击捏合）：
- 现在是**兜底**，不是主路径；
- `startPlay` 里若判定到 pdf 会打告警：`[READER-ENTRY] PDF 误入 ReaderPage3（入口应走 ReaderEntry -> PDF_VIEWER）`；
- 将来确认长期无告警后，可整段删除（届时 `FMT_ZOOM_ENABLED` 一并评估）。

## 四、闸门

`scripts/check-single-path.mjs` 的 `reader-fact-write` 规则：
- **scope**：`pages/view/Reader/` **全目录** + `common/reader/`（P1 由"4 个文件"扩来）；
- **预算 0**：阅读器只能通过 `ReaderPorts` / `BookmarkPorts` 写 `books` / `bookmarks` 事实；
- 意义：以后再加阅读页，默认就落在闸门里，不会重演 `PdfReaderPage` 那种"新页面绕过闸门直写"。
