## 3. 每批固定验收流水线（Lead 执行）

```
1) 审 diff：git status / git diff --stat（越界立即回退）
2) MCP check（改动文件，绝对路径）
3) devecocli build --modules entry           → 必须 BUILD SUCCESSFUL
4) node scripts/check-all.mjs                → 必须 5/5（含 AppStorage 85 键预算）
5) 真机：hdc install -r + force-stop + start → 比较 dumpLayout 的 bounds 关键值
6) 独立 commit（首行不带版本号）+ docs 追加证据
```

回退：每批一个 commit，`git revert <sha>` 即可；DB 迁移批额外要求"装老包→装新包→数据完好"的双向验证。
