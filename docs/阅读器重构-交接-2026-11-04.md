## 2. 已经建立的机制（**不要绕过**）

| 机制 | 位置 | 作用 | 破坏后果 |
|---|---|---|---|
| **纯记录层** | `common/reader/ReadSettingRecord.ets` | 13 字段形状、`defaultReadSettingRecord` / `fromReadSettingRecord` / `toReadSettingRecord` / `pickReadSettingFields` / `isValidReadSettingRecord` / `hasLeakedObservingKeys`，全是纯函数 | 落盘/下发若绕过它，`__ob_` 脏键会再次污染持久位（历史事故） |
| **响应式模型** | `common/reader/ReadSettingState.ets` | `@ObservedV2` + 13 个 `@Trace`；`snapshot()` 是**唯一外部出口** | 直接把模型实例交给 Preferences 或 `JSON.stringify` ⇒ 写出 `__ob_` 前缀键 |
| **边界出口** | `ReaderPage3.settingForBoundary()` | **22 处**（16 `setPageConfig` + 6 `putSync('ReaderSetting_*')`）全部走它 | 有人新增直传 ⇒ 边界收口失效（单测会红） |
| **迁移登记表** | `ReaderPage3.MIGRATED_SETTING_FIELDS` | 记录哪些字段真源已在模型 | 漏登记 ⇒ 该字段被页面快照回灌覆盖（功能回归） |
| **两个棘轮** | `scripts/tests/read-setting-record.test.mjs` | `RATCHET_DIRECT_WRITES`（总数不许涨）/ `RATCHET_UNMIGRATED_WRITES`（未迁字段直写点，**真正的进度计**） | 进度计失控，迁移做完也不知道做到哪 |
| **真机操作工具** | `scripts/reader-ui.mjs` | `dump` / `bounds <文字>` / `tap <文字>` / `diff a.json b.json` | 手写命令会重复踩坐标漂移的坑 |

### 2.1 每迁一个字段必须做的四件事

1. 字段名加进 `MIGRATED_SETTING_FIELDS`；
2. **运行期写点**：`this.settingState.X = v;` 紧跟 `this.rsProjection.X = this.settingState.X;`
   （前者是权威、后者供纯函数；只写前者 ⇒ 自绘层排版拿旧值，只写后者 ⇒ 引擎/落盘拿旧值）；
3. **装载期写点**（读持久位 / 接续参数 / 全局字体记录 / 迁移补丁）：`模型 = 来源值`（**方向相反**）；
4. 同步下调 `RATCHET_UNMIGRATED_WRITES`。

> **最容易犯的错就是第 3 步写反。** 已实测复现过一次：写反后用户保存的设置每次进书都被默认值顶掉。
> 单测里有一条专门钉这个方向（`装载期方向：…不是…（防回归）`）。

## 4. 未写进注释、但必须知道的（踩坑史）

| 坑 | 具体表现 | 正确做法 |
|---|---|---|
| **真源方向写反** | 用户保存的设置每次进书被默认值顶掉 | 装载期 = 来源→模型；运行期 = 模型→快照 |
| **模型实例直接落盘** | Preferences 出现 `__ob_` 键（本工程历史污染过一次） | 一律 `snapshot()` / `toReadSettingRecord()` |
| **页面用 `@State` 持模型** | 编译报错（官方 `arkts-v1-v2-mixusage` 限制条件 2） | 普通成员持有 |
| **`@Trace` 不能观察 Function** | 模型里放回调字段无效 | 回调一律放页面/组件参数 |
| **`arkts-no-misplaced-imports`** | import 写在常量后 ⇒ 编译失败 | import 必须在所有语句之前 |
| **用正则检查代码** | `\s` 含换行 / `String.raw` 里 `\t` 不是制表符 / `===` 被当成赋值 —— 连错三版 | 逐行 split 解析，正则只匹配行内小片段 |
| **坐标会漂** | 面板/弹窗高度随内容变化，两次 dump 差 40~60px；dock 按钮**文案**也会变（夜间/日间） | 用 `scripts/reader-ui.mjs`：先 dump、按 `bounds` 算中心、点完用日志确认 |
| **"点了没报错" ≠ 生效** | 已误判 3 次（切档、复原行距、点色格） | 必须用 `hilog`（`switchReadMode` / `readMode loaded` / 引擎 `setConfig`）或再 dump（`checked`/`backgroundColor`）确认 |
| **MCP check 输出会截断并夹带重复片段** | 裸正则数诊断码会翻倍（实测 119 vs 43） | 按 `code + range.start` **去重**后再比 |
| **多行 import 不报未使用符号** | `import { a, b,\n c }` 里某符号未用，MCP 不报 | 抽走唯一用途时，**整条 import 手动核对一遍** |
