# 喵阅 · 6 张宣传图：提示词与出图说明

> 两条路线，按需选：
> - **路线 A（推荐 · 已交付）**：本地合成 —— 真实截图**一像素不改**，只做裁切/圆角/投影，文字由脚本绘制。
>   产物在 `promo/out/1080x1920/`（9:16）与 `promo/out/1080x1440/`（3:4），脚本 `promo/make_posters.py`。
> - **路线 B（豆包 / 即梦等文生图）**：让 AI 出**背景底图**，再合成真实截图；或直接让 AI 出完整海报。
>   ⚠️ 直接让 AI「照着截图重画一张带文字的海报」的结果通常是：**UI 被重绘、菜单名/按钮名变糊或变错字**。
>   生成式模型不理解像素级 UI，这是通性【推测，未在本机实测豆包/即梦当前版本】⇒ 建议 AI 只负责**背景与光效**。

## 附：一键改文案 / 改配色（不用碰渲染逻辑）

编辑 `promo/make_posters.py` 顶部的 `POSTERS` 表，每项：

| 字段 | 含义 |
|---|---|
| `src` | `promo/src/` 下的底图文件名 |
| `crop` | 从 1320×2848 原图取哪块 `(左, 上, 右, 下)` —— 决定"这张图展示哪个功能" |
| `title` / `sub` | 主标题 / 副标题（**用户文案原样**，未改写） |
| `c1` / `c2` | 背景渐变（深 → 亮） |
| `accent` | 强调条 + 光斑颜色 |

生成命令：
```powershell
python promo/make_posters.py                      # 9:16 全 6 张
python promo/make_posters.py --size 1080x1440     # 3:4 全 6 张
python promo/make_posters.py --only 1 6           # 只出第 1、6 张
python promo/make_posters.py --format jpg         # 只出 JPG
```
